Frequently Asked Questions

Click a question to open or close the answer.

CinemaHub is a movie information website built for the Web Development course. It collects a small hand-picked catalog of popular films, shows their trailers, keeps a ranking table with your own ratings and lets you send feedback to the team. It is useful for students who want to see how HTML, CSS, jQuery and a public API work together in one real project.

Use the round button with the moon icon in the top navigation bar. The theme is stored in localStorage under the key "cinemahubTheme", so it is applied again every time you open or refresh any page of the site - the choice is remembered across the whole website.

No. All content is available to guests. However, the rating form on the Reviews page is unlocked only after you sign in, so that we can show a different interface to signed-in users. The sign-in is a demo sign-in: only your display name, e-mail address and login time are stored in localStorage, and the password is never saved.

The form validates the input the same way a real login would: the e-mail must match a regular expression pattern and the password must be at least six characters long. Validation messages are shown under each field, and the Sign In button only works when every field is valid.

The "Find a title online" block on the Movies page and the "On TV today" block on the Home page use the free TVMaze API (https://www.tvmaze.com/api). The data is requested with fetch(), parsed as JSON and rendered into the page with jQuery. No API key is needed, which is why it also works on the published GitHub Pages version of the site.

Every request has a 12 second timeout and a try/catch block. If the server answers with an error status, if the connection drops or if the answer takes too long, the status line explains the problem instead of leaving an empty page, and you can simply press Search again to retry.

Yes. If you are signed in you can add a new row, edit an existing one or delete it with the buttons in the Actions column. Every change is written to localStorage, so your personal list stays in the browser even after a refresh. The Sign Out button clears the session.
